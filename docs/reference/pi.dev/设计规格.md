# pi.dev 设计规格（实测提取）

**提取日期：** 2026-10-08
**方法：** 抓取 `pi.dev/style.css`（196 KB）解析真实令牌 + 首屏截图比对
**用途：** 复刻到 QT 的落地页

> **更正：** 我上一轮把 pi.dev 说成"深色终端风格"是错的。实测 `html` 背景是
> `rgb(235,231,228)`——**温暖米白**，且带极淡的网格。用户是对的。

---

## 一、视觉基调

**米白纸感 + 极淡网格 + 衬线排版 + 少量高饱和色块。**

像一张方格纸（graph paper），不是深色终端。深色只出现在**嵌入的终端演示**里（那是内容，不是页面基调）。

---

## 二、配色（完整调色板）

pi.dev 用的是**命名色**，名字本身就说明了调性（parchment / moonstone / driftwood…）：

| `--color-cool-white` | `#f0f2f3` | 冷调白（终端框底） |
| `--color-parchment` | `#dacbc2` | 分隔、次级底 |
| `--color-evening-blue` | `#252f3d` | **正文与标题色**（深蓝灰，不是纯黑） |
| `--color-warm-black` | `#13110f` | 最深色（标识块、终端底） |
| `--color-warm-40` | `#5c5650` | 次级文字 |
| `--color-warm-30` | `#8b847d` | 三级文字/说明 |
| `--color-driftwood` | `#5c5752` | 中性文字 |
| `--color-accent-blue` | `#6a9fcc` | **强调色**（标语里的斜体词、链接） |

## 三、字体

```css
--serif: "Plantin MT Pro", "Plantin MT Std", Plantin, Georgia, serif;
--mono:  "Commit Mono", "SFMono-Regular", ui-monospace, Menlo, Monaco, Consolas, monospace;
```

| 元素 | 字体 | 字号 | 字重 | 其他 |
| :--- | :--- | :--- | :--- | :--- |
| 大标题 | serif | **47.7px** | 400 | **italic**，行高 1.02，色 `rgba(37,47,61,.96)` |
| 导航 | serif | 18px | — | — |
| 正文 | serif | 18px | — | — |
| 终端/代码 | mono | — | — | 终端里用 |

**注意：正文是衬线，不是无衬线。** 这是它区别于普通 SaaS 站的关键。

> 落地建议：`Plantin MT Pro` 是商业字体。用 **Georgia**（系统自带、衬线、可读）作替代，
> 视觉接近且零成本。中文配 **思源宋体 / Songti SC**。

## 四、网格背景（可直接复制）

pi.dev 的网格在 `body::before` 上，用 4 层渐变叠出来：

```css
body::before {
  --grid-gap: calc(var(--page-grid-cell) / 5);   /* 20px / 5 = 4px */

  background-image:
    /* 细线：横、竖，每 4px */
    linear-gradient(var(--page-grid-minor) 0 1px, transparent 1px var(--grid-gap)),
    linear-gradient(to right, var(--page-grid-minor) 0 1px, transparent 1px var(--grid-gap)),
    /* 粗线：横、竖，每 20px */
    linear-gradient(var(--page-grid-major) 0 1px, transparent 1px calc(var(--grid-gap) * 5)),
    linear-gradient(to right, var(--page-grid-major) 0 1px, transparent 1px calc(var(--grid-gap) * 5)),
    /* 交叉点 */
    radial-gradient(var(--page-grid-cross) 1px, transparent 1px);
}
```

**尺寸与颜色变量：**

```css
:root {
  --page-grid-cell: 20px;
  --page-grid-inset: -8rem;

  /* 浅色模式（实际使用的） */
  --page-grid-minor: #252f3d08;   /* 3%  深蓝 */
  --page-grid-major: #252f3d12;   /* 7%  */
  --page-grid-cross: #252f3d1d;   /* 11% */

  /* 深色模式（备选） */
  /* --page-grid-minor: hsl(218 60% 80% / 0.009375); */
  /* --page-grid-major: hsl(218 60% 80% / 0.02625);  */
  /* --page-grid-cross: hsl(218 60% 80% / 0.075);    */
}
```

**关键：线极淡（3%–11% 不透明度）。** 网格是"纸的质感"，不是"图表辅助线"——**做成明显的格子就毁了**。

## 五、布局栅格

`.page-shell--home` 实测：

```css
--page-shell-columns: minmax(0, 1.4fr) clamp(22rem, calc(100% - gap - 40rem), 36rem);
--page-shell-padding: 3.5rem 2rem 4rem;
--home-nav-logo-gap: 3.5rem;
--home-logo-headline-gap: 2.75rem;
--home-hero-flow-gap: 1.5rem;
--home-demo-column-floor: 40rem;
```

**就是你说的「左栏演示 + 右栏文字」：**

```
┌──────────────────────────┬─────────────────┐
│                          │                 │
│   左栏 1.4fr             │   右栏           │
│   （演示/终端/截图）      │   clamp(22–36rem)│
│                          │   （文字说明）    │
│                          │                 │
└──────────────────────────┴─────────────────┘
```

右栏**有最小 22rem、最大 36rem 的夹紧**——保证文字行宽舒适，不会随窗口无限拉长。

## 六、组件特征

| 组件 | 特征 |
| :--- | :--- |
| **方块标识** | 建在 20px 网格上的"棋盘"（`--home-hero-logo-board-columns` / `-visible-rows`），所以有俄罗斯方块感。**可点击/可动** |
| **标语** | 衬线斜体，关键词用 `--color-accent-blue` 高亮（如 "…but this one is **yours**"） |
| **顶部公告条** | 极细，`--site-announcement-height` 控制高度，可折叠 |
| **终端框** | 浅蓝调底（`--color-cool-white`），等宽字体，`asciinema` 录制回放 |
| **滚动提示** | 底部 `SCROLL TO CONTINUE`，小号等宽 |

## 七、应用到 QT：照搬什么、改什么

### ✅ 照搬（你要求的）

| 项 | 说明 |
| :--- | :--- |
| 米白 + 网格背景 | 直接复制上面第 4 节的 CSS |
| 衬线排版 | Georgia 替代 Plantin，标题用斜体 |
| 正文色 `#252f3d` | 不用纯黑 |
| 强调蓝 `#6a9fcc` | 标语高亮、链接 |
| 左 1.4fr + 右 clamp(22–36rem) | 演示 + 文字布局 |
| 调色板整体 | 全部命名色可用 |
| 克制的动效 | 少而慢 |

### ⚠️ 必须改（品牌身份，不是布局）

| 项 | 为什么 |
| :--- | :--- |
| **方块标识** | 那是 Pi 的品牌标记。**换成 QT 自己的**——同样是网格上的方块构成，但形状不同（比如排成 Q 或 T 的字形）。改起来很便宜，答辩时却是硬伤 |
| **标语文案** | 写 QT 自己的。可以借"…but this one is yours"的**句式节奏**，但内容要讲你的研究工具 |
| **终端演示内容** | 换成 QT 的实际操作（划选 → 打码 → 出图） |

### 🔒 阅读区例外

**工作台里的访谈正文区保持浅色高对比**，不要用网格背景——网格会干扰长文本阅读。落地页可以铺网格，工具里不要。

## 八、实现清单

落地页需要：

```
landing/
├── 首屏       米白网格 + 方块标识 + 衬线斜体标语 + 「进入 QT」大按钮
├── 演示区     左栏 1.4fr：界面截图/动图  右栏：文字说明
├── 方法学区   主题分析六阶段 → 工具如何支撑
├── 差异化区   「数据不出本机」+ 开源可审计
├── 数据集区   Tian 2021 / TU Delft（公开数据）
└── 进入按钮   → 跳转工作台
```

**技术栈建议：** 纯 HTML + CSS，不引框架。网格是 CSS 渐变，无需图片。字体用系统衬线。整个落地页可以是一个 `landing.html` + 一段 CSS，**零依赖**，符合项目调性。
