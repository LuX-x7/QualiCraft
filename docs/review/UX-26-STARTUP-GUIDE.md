# UX-26 · 空项目起步、继续上次项目与可跳过引导

2026-10-16。基线 `c3e7fc95c5d17cdd3992fa2e29960b055ca9108d`；完整本地提交见 Git 和审核包 `COMMITS.md`。

## 本轮范围与行为

用户明确授权工作台起步／继续工作／简短引导。只改这条工作流、对应回归和审查文档；网站、报告、统计、绘图、CSV、默认能力块与项目 schema 不变。没有推送、部署或自动部署配置修改。Windows 暂缓、未验证。

- **首次进入本地工作区**：未记住明确选过的项目时显示起步页，提供 Import a document、Try Bologna、已有项目选择和 Restore project JSON，不再自动打开列表第一项。新空数据库也不再自动创建虚构示例。已有项目不会被清空或转换。
- **创建空项目**：先命名，明确点击 Create & import 才创建项目。取消命名不写记录；创建后取消导入则保留该空项目，可稍后继续。空页保留一个清楚的主导入按钮；建码和原绘图工作流预设收在 Optional tools，原默认开关不变。
- **继续工作**：成功打开项目后，浏览器按稳定项目 ID 记住选择；下次刷新自动回到该项目和 UX-25 的文档／段落位置。新增或编辑其他项目不会抢占它。无效版本、损坏记录或不存在的 ID 回到起步页，不默选别的项目。Back to start 保留上次选择，起步页可点 Continue。
- **Bologna 示例**：主动点击后，服务器只以只读 SQLite 连接读取仓库的固定 Bologna 模板，验证并创建独立新项目 ID，增加明确的 `example_copy` 审计事件；文档、编码、标注、原来源、能力块与 schema 保留。模板不被编辑。可编辑示例显示一行可展开说明，并可新建自己的项目。公开只读演示仍直接打开已安装样例，明确标注只读，不能用示例／引导执行写入。模板未安装时不展示试用入口。
- **三步轻引导**：导入文档 → 选句赋码 → 核对关系／导出。只显示当前一步，按实际文档与已保存标注推进；不会发送模型请求、自动编码或强开能力块。Back／Next 可查看说明，Skip／×／Done 关闭，Help 可重开；Escape 和焦点返回可用。完成导入／编码后保持原操作结果与原句定位焦点。
- 引导和上次项目偏好仅存本机浏览器，不进入项目、审计、备份或导出；引导按项目区分，禁用存储时保留会话内关闭行为。引导步骤不是研究完成度。已有／恢复的项目不自动弹出教程，公开示例只显示可实际执行的查看操作。
- Help 在手机复用原项目切换行，示例说明默认折叠，不挤高原阅读栏。返回起步页时后台任务完成检查对空项目指针做保护；分析请求、定义和结果未改。

本轮产品文件为 `qualicraft/server.py`、`web/app.js`、`web/style.css`。server 变更限于取消隐式示例、新增显式 Bologna 复制和能力可用标识；网络响应、启动器和健康检查函数保持一致，UX17-05 没有顺带修复。
