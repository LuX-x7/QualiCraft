上一版写"仓库中不存在删除项目的路径"，并说这是用 grep 输出关闭的。

准确结论：**工作台的项目存储没有删除项目的路径**；**网站 CMS 有删除路径**，
删的是 CMS 内容（pages / blocks / entries / leads / translations / media），
且 CMS 没有快照机制。CMS 属 T6 的删除范围。
