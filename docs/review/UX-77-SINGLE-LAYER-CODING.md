## 统一任务范围

## 实现

- Coding桌面正文左、唯一完整项目树右。左侧只留文档／导航；逐段重复树替换为简短编码数量。原始高亮和多码关联保留。
- 右侧树与AI建议复用同一区域；默认树，AI按需打开。元数据、范围、来源、定义／备忘录／编辑入口在详情内，不删除研究功能或数据。
- 显式Theme／Category／Code角色按保存值显示；未指定就显示Not assigned，不按深度推断研究含义。已有滚动汇总计数保持。
- 点击节点只定位当前文档内自身及后代原句，下一处／上一处切换；当前文档无匹配不换文档。全文／搜索／筛选不被隐式改写；隐藏匹配需明确选择显示全文。筛选为独立动作。
- 首次临时查看保留源文本绑定的阅读、搜索、筛选及概览返回点。继续编码恢复该点；在此继续停留所看原句；Escape退出。源文本／项目／文档变化使旧点失效。返回数据只在内存，不进项目或浏览器持久存储。
- 大于1000px为常驻右树；不超过1000px通过单一原生对话框打开同套树，关闭恢复原位置。编辑表单替换该对话框，关闭回树，不叠模态框。1024px压缩左导航，390px保留入口。
