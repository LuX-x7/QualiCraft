## 六项反馈对应的修改

| 用户反馈 | 当前候选的具体实现 |
| --- | --- |
| 轨道仍平面、缺少粒子与鼠标互动 | 改为自写透视投影与前后两层 Canvas：轨道倾角、距离缩放、前后遮挡、确定性粒子场和多列粒子拖尾。鼠标位置控制平滑视角；卫星的 hover/focus 显示对应模块说明，手动暂停保留用户控制视角；减少动态效果则关闭自动运动及鼠标视角变化。半径不编码研究值，没有复制第三方代码／资产 |
| QT 应在正中 | QT 位于同一首屏轨道系统的几何中心，文字与唯一工作台入口也居中；不再把品牌与插图分成左右两栏。网站标志仍只显示 QT，软件引用和项目名称不改 |
| 五模块更工程化，强调积木组合 | 线稿加入基准线、尺寸刻度、定位孔与等轴底座；可用原生按钮取下／接回积木，按接回顺序绘制概念路线，支持复位与路线锚点。明确这只是示意，不把它冒充实际项目开关；真实六项能力开关说明保留 |
| 左小右大、图需点击／裁切、关系不明显 | 演示窗口约占可用宽度 70%，正文 22px、图中读值 20px。移除焦点无限锁定；九个阅读段落为 Import、Coding、Analysis、五个 Plot、Export，五图直接随自然滚动出现，原生滚动不被劫持。首页使用完整 CSV 概览，不复用带最小宽度和内部滚动的报告图。关系图把高亮原句、编码、父主题、根主题分别做成可交互节点；连线按真实 DOM 边界测量，来源和全路径仍可展开 |
| 数据／方法／边界过于静态 | 线稿基准线在进入视口时绘制，hover/focus/展开时有纸张、箱盖、连接与验证线的动作；内容和原生展开交互均保留。方法连接线在动画结束后恢复完整实线，避免把未绘完的线误认为结构缺失 |
| 字偏小、背景不统一 | 全首页使用淡 40px 工程网格，文字与图表置于实色纸面容器。正文 20–22px、节点 19–21px、方法标题 30px、主要图注 14–16px，次要元数据通常 11–13px。手机全九段顺序内联，原句和节点 21px；密集图仍有大字号准确读值与原生选择器 |

保留六个首页板块，不增加独立推广区。保留五段真实录像与静态替代、完整方法和引用、产品边界理由、生成的数据卡。所有例证仍只来自原 Bologna CC0 资产。
