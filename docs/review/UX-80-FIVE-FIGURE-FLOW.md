# UX80 / 75D 五类图选择、生成与空状态

2026-10-20。用户授权只用Bologna临时副本，修复五图入口和空状态；不改统计或图形结果，通过后仅同步QT。Windows暂缓，不推送、不动其他项目。

## 实际复现

- 五种图原来只藏在下拉菜单，绘图能力关闭时主导航还会完全隐藏Figures；用户导入／编码后可能找不到入口。
- 界面统一要求两条编码，错误拦住实际可用的一条编码频次／覆盖／层级／累计图。
- 共现预览捕获所有错误后都显示“无重叠”，Bologna原本有可绘制编码对时注入503也被误报；段落模式空结果仍讲重叠区间。故障注入只影响受控浏览器，不是服务器真实停机。
- 改设置就自动请求绘图，缺少明确生成／空／错误状态；下载在尚无成功预览时可用，容易重复失败。

旧界面证据before/，实际基线5 SVG和CSV；新增首批回归在旧版失败，raw/tests-before.txt。旧版通过浏览器专用加载HEAD源码重现，没有回滚线上。验收脚本的Blob fetch被CSP正确阻止、恢复请求漏Content-Type两次失败均保留，修正脚本后复现；未放宽产品安全策略。

## 改动

- Figures入口常驻。能力关闭时显示明确启用入口，只为该项目添加plotting，不自动打开其他能力。
- 五种图改为一组可见原生单选项；先选择，再点Generate preview。主要设置直接展示，外观设置按需展开；改设置不请求绘图，过期预览不能下载。
- 仅以有有效已保存标注作为通用前置条件；空共现交给原绘图路径判断。零编码、缺依赖、能力关闭分别说明并保留返回Coding入口。
- 只有原后端已知400无数据响应归为空结果；共现解释根据本次请求的overlap／unit及Top N生成，不建议为了出图编造标注。503／401等保留真实错误并可重试。
- 生成中／成功耗时／空结果／失败明确显示；重复生成被阻止，切换选项使旧请求失效。下载仅对当前成功预览开放，准备下载与失败单独反馈。
- 保留原SVG及原尺寸放大查看、完整内容滚动、完整下载包。层级图预览窗口可滚动，不裁改图文件；累计说明明确按文件名排序，非访谈时间顺序。
- 原生键盘选择、状态焦点、Escape返回；外观展开状态保留，编辑标题后首次点击Generate不因blur重建控件丢失，Tab／Enter同样有效。
