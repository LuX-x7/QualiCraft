## 用户澄清与已实现范围

用户用工作台网络截图澄清：需要的是**主题大圆点、编码小圆点、可以展开原句的交互网络**，不是三列卡片或纵向文字树。该澄清取代 UX-20 W02 中对图形形态的早期建议。

- Coding 与 Analysis 分别成为演示区里持续挂载的独立画面，不再只存在于随滚动替换的 sticky 画布。直接锚点为 `/#story-coding`、`/#story-analysis`，五模块入口继续可定位；正常滚动不需要先点击标题。
- Coding 样板展示一份原句与一次已保存的赋码：纸面选区、字符范围、编码和编码本位置。保留自己的细线、标尺与铅笔图形，收束留白、字号和边框。它是说明性图解，不冒充一次真实新建操作。
- Analysis 展示圆点网络，包含主题、编码、可展开的原句节点和真实连线。悬浮、焦点或选择同步强调关联并显示完整原句与路径；支持鼠标拖拽节点、主题筛选、明确的节点选择器、展开/收起原句、缩放及重置。
- 键盘方向键、Home/End 遍历节点，Enter/Space 展开编码的原句；原生 Tab 可遍历控件。PageUp/PageDown 与章节标题方向键继续在工作步骤间导航。
- 手机保留同一张节点/连线网络，默认 50% 概览；可放大、原生横向查看，并通过触摸控件选择精确节点及读取大字号完整原句。没有用隐藏连线的文字路径代替网络。手机验证为 Chrome 模拟触摸，不是真机签字。
- 既有 Import、五图和 Export 的素材、数据与绘图组件不改；演示布局按“Import → 常驻 Coding → 常驻 Analysis → 原五图与 Export 滚动演示”组织。录像仍在各步骤的折叠区可到达。

## 数据身份与限制

网络来自已经绑定现有 manifest 的 `website/lib/report/bologna-evidence.json`：**389 条已保存报告例证**，含 313 个不同主题/编码节点，其中 8 个主题、305 个编码。初始画面另展开 1 个真实原句节点，因此是 314 节点、322 连线：305 条父级关系、1 条赋码关系、16 条现有 CSV 共现对。不是工作台 874 条标注的完整导出，也不把报告例证数解释为研究总数。

- 身份使用 `theme:<ID>`、`code:<ID>`、`passage:<标注ID>`；节点和来源保留完整稳定 ID，不依靠显示名称去重。
- 实线来自保存的父级路径和赋码；虚线只连接能与现有共现 CSV 唯一对应的名称，值直接取 CSV。重名不能唯一匹配时不猜连线，回归对此有明确断言。
- 节点大小表示类型，布局位置用于解释关系，不代表新统计量或研究意义。有限的确定性力布局不改变数据；拖拽只改变当前网站显示位置，不写回项目。
- 原句详情保留文档名、Unicode 范围、标注/编码 ID 和文档哈希。计数单位句继续从 manifest 的 credit 传入，不另写 CREDIT 常量。
- 现有报告资产、计数表、数据卡和源数据库保持原字节。未新增统计定义、后端请求或分析功能。
