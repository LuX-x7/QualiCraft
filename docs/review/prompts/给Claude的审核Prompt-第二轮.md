  这套机制有没有你一眼看出的问题？比如并发、磁盘占用、恢复路径是否真的可用？
- **启动自检**（材料第 4 节）：它暴露了 `render.yaml` 与 Dashboard 的值可能不一致，
  但**没有强制一致**。这是不是留了一半？
- **图的单位声明**（材料第 5 节）：把口径写进图的署名和副标题，够不够？
