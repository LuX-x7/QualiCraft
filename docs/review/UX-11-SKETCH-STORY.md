## 当前方案

用户最终确认首页六段：QT 标题与短说明 → 独立的五个手绘工作步骤 → 左侧演示、右侧滚动说明 → 数据来源 → 两种方法 → 不做什么。页脚只保留引用／许可、反馈和动效选择。五步骤不能与实际六项能力开关混淆；真实开关说明按需展开。

网站可见标志采用自有像素 **QT**，不再并排显示 QualiCraft。软件引用、仓库名称、数据库和工作台名称没有改名。

用户否定了第一稿绕 QT 的平面螺旋，本稿改为独立的手绘卫星系统：首屏左侧保留 QT 和一个工作台入口，右侧五个卫星分别表示五个工作步骤。使用自写投影几何、不同周期、远近缩放、分段轨道及拖尾；焦点／悬浮显示相应说明并暂停，提供手动暂停、站内减少动态效果、离屏暂停。它是明确标注 schematic/not to scale 的概念图，半径与大小不编码研究数值。参考阶跃报告的空间运动方式，没有复制其代码、图像、数据、字体或文案。

五个独立线稿提供原生锚点与 hover/focus 动画。桌面按自然页面滚动切换 sticky 左侧；方向键、Home/End 可依次访问右侧步骤，普通滚动不被劫持。手机改为五个图文顺序内联，无须切标签。线稿首次进入视口时演示，静态与减少动态效果保留信息。

Import 以文件→可读文档呈现；Coding 与 Analysis 显示真实 Bologna 原句高亮→稳定编码 ID→完整主题祖先路径，不伪造关系；Analysis 明确只是一条保存关系的示意，完整关系图仍在工作台 Insights。Plotting 将已有五种 CSV 交互图放入左侧场景，准确读值并保留原图／CSV／报告入口；Export 用文件盒及四个实际导出格式解释用途，不假装图解已完成下载。原来的五段真实录像和静态替代仍在展开项中。

数据来源、两种方法与产品边界改为自有图解，完整数据卡、方法对照、引用与理由保留在展开项。图注单位仍来自 manifest，数据卡仍来自原生成 JSON。共享 DataPlot 样式从报告页提取，报告的 sticky 读值、原 SVG、完整五表和十个下载入口保留。
