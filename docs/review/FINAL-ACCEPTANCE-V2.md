## 1. 用户明确的最终体验

用户导入一份或大量访谈，在研究问题和案例单位明确的前提下选择 TA、CA 或 QCA，通过 Import → Coding → Analysis → Plotting → Export，得到可检查、可修改并能再次导出的研究报告、适用于目标投稿规格的图，以及同一数据与参数对应的可运行代码。报告格式已参考用户提供的三列 Analysis Table — Themes, Categories, and Codes 与 Narrative Analysis。该结构可作结果章节基础，尚需证据链、反例、方法与真实披露；私有样板已生成可编辑Word，但产品内编辑／保存／恢复仍待实现。

“随意上传”必须落到公开的格式／大小／容量边界；不能解释为任意扫描件、文件类型、规模或研究设计均可无条件处理。“一百份文件”也不能自动当作“一百个独立案例”。

报告是研究者审核的分析成果。工具应支持逐步工作、证据校验和明确的人工裁决；不以一键生成未经审核的最终研究结论代替研究。助手、外部模型建议、人工判断和工具计算的来源要如实区分。

## 2. 三种方法必须有真实差异

| 研究路径 | 需要支持的研究步骤 | 方法相关输出与门禁 |
| --- | --- | --- |
| Thematic Analysis（TA） | 明确采用的 TA 路径；熟悉资料、编码、发展／审阅主题、解释与反身性记录 | 可追溯的主题／代码及原句、叙述与反例；不能用频次或统一编码一致率替代所有 TA 路径的质量判断 |
| Qualitative Content Analysis（CA） | 明确分析单位、类别与编码规则、归纳或理论引导等具体方式、语境解释 | 类别／编码表、证据矩阵、解释；有理由时报告计数。CA 本身可以是完整方法，并非 TA／QCA 必经的前置步骤 |
| Qualitative Comparative Analysis（QCA） | 案例定义、条件与结果集合、校准依据、真值表、配置分析与稳健性／反例回查 | 数据与校准矩阵、真值表、配置结果、充分／必要性相关指标及代码；不能把共现、编码频次或 Themes 表改名当作 QCA |

用户材料已明确当前作业是 Qualitative **Content** Analysis（原稿也缩写QCA），不是集合论 Qualitative **Comparative** Analysis。用户在澄清后明确选择仍保留三种最终产品方法，Comparative作为独立新增能力。本次两份结果按内容分析核对；表格加Narrative Analysis不等于完整Comparative流程。仅两个案例与访谈中的主题不能替代条件／结果与校准设计。

三个方法可共用原文、稳定 ID、编码、笔记、引文定位与审计基础；Analysis 的流程和报告内容必须按方法变化。新目标授权了后续方法能力规划，但不把校准／QCA引擎在本轮偷偷实现，也不新增无关词频、全文导出或语义检索。

表格中的层级、例句、标题与叙述应一致；不得为了套版虚构主题数量、引文、受访者资料、知情同意、伦理批准、饱和或计算结果。未知项明确标为待补。模板若是结果章节，不强迫它承担完整论文全部章节，但应明确引用研究设计／方法／伦理记录所在位置。QCA分支要有自己的校准／配置章节，不能硬塞进同一棵主题树。

## 5. 第五模块的目标设计（已有外部可编辑样板，待产品实现）

保留现有四项导出，新增“研究报告”：由已确认项目记录和可追溯证据组成草稿，支持修改分析表、方法相关章节、叙述、图题和局限，保存版本、比较和恢复，再次导出。默认目标是可编辑的报告源文件与提交／分享用副本；首个样板已交付可编辑DOCX及Markdown；产品优先支持可编辑源文件与可分享副本，具体PDF流程另验，不能只输出不可修改的PDF。

原句、编码 ID、统计值、图表参数和输出资产要与当前项目版本关联。改叙述不静默改原文或计数；项目编码变化后报告应标记过期并让用户检查／刷新。研究者可以删除／调整报告组织；真实引文与计算值必须保留来源，避免编辑后伪装为原始输出。自动 Methods record 是活动记录，不等于完整 Narrative Analysis 或报告生成器。

### 编码原文对照文档：新增必交付内容

独立导出完整已编码文档，并可选纳入研究报告的证据附录。正文保留未编码语境、原段落顺序和精确高亮；右侧为对应原句的实际祖先树，支持同句多码、重叠、跨段、多层及未归组编码；同名使用路径／稳定ID区分。每条关联可按文档ID、标注ID和Unicode范围回查。导出默认全文，不被临时搜索、筛选或当前视口裁掉。层级按保存记录与已明确的方法角色显示，不能虚构Category／Theme。

用户要求的“原样”是Coding正文、高亮和对应归属的忠实呈现；内容必须可读、可复制并方便继续写作。建议自包含HTML保留双向定位、可编辑DOCX便于整理叙述，PDF用于固定分页审核；格式组合为实现建议，具体切片另冻结，不将三格式都冒称用户已确认。已实现的格式须完整对应、长树跨页不丢标签，不能仅导出截图或CSV。完整规则及十项待执行标准见 [UX-42](UX-42-CODED-TRANSCRIPT-EXPORT.md)。现有四导出、五图、计数表及复现代码保留。

“几乎与手工相同”不是唯一通过标准。先对齐研究问题、方法、分析单位与码本含义；严格检查工具是否忠实保存／计算，再由研究者和 mentor 讨论分析是否有证据、是否遗漏关键内容。不同解释可以合理存在，不能将人工答案当作可偷偷拟合的目标，或把 AI／助手判断冒称独立人工。

## 8. 方法与报告依据

- Graneheim & Lundman (2004), [Qualitative content analysis in nursing research](https://pubmed.ncbi.nlm.nih.gov/14769454/)：本次实际模板的方法依据；意义单位、凝练、抽象、代码、类别、主题与可信度。

- Hsieh & Shannon (2005), [Three Approaches to Qualitative Content Analysis](https://journals.sagepub.com/doi/abs/10.1177/1049732305276687)：CA 的不同分析方式与意义解释，不是其他方法的统一前置步骤。
- Braun & Clarke, [Understanding TA](https://www.thematicanalysis.net/understanding-ta/)：TA 包含不同取向，不能用一套固定质量指标覆盖所有取向。
- Dușa, [Calibration](https://bookdown.org/dusadrian/QCAbook/calibration.html)／[The truth table](https://bookdown.org/dusadrian/QCAbook/truthTable.html)：QCA 的集合校准、条件／结果与配置分析。
- [SRQR](https://www.equator-network.org/reporting-guidelines/srqr/) 与 [COREQ](https://www.equator-network.org/reporting-guidelines/coreq/)：研究报告透明度与访谈报告的检查依据。
