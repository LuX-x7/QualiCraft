## 建议的统一方向

纸面、QT 像素标志、两种强调色、清楚的留白构成共同语言。手稿感集中于容器、结构连接和模块组合；数据坐标、刻度、节点层级和原句排版保持精确清晰。不能把添加装饰性线条或更多动画当作完成视觉统一。

首页一级结构继续保持：QT 首屏 → 五模块积木 → 左演示右说明 → 数据来源 → 两种方法 → 不做什么。**关系图留在演示区内，不增加新的顶级营销区块。** 网站负责解释，报告负责核查，工作台负责阅读与操作；三者不必具有相同的信息密度。

### W01 · 热图的可移动放大窗口（待实施）

- 左侧保留可读的大格子；右侧提供有清楚行列定位的全矩阵概览，在概览上移动矩形取样框。矩形比圆形裁切更适合保持矩阵的行列结构。
- 鼠标移动框选区域，左侧同步对应的真实 CSV 单元格；悬停大格子显示完整访谈名、编码名和值。允许固定当前值，防止查阅时因鼠标离开而丢失。
- 触摸点击或拖动概览定位；键盘方向键移动窗口与数据焦点。无悬停设备也能完成所有操作。
- 概览如采用原 SVG，必须核对原图单元格与 CSV 的真实坐标映射；不能凭图片百分比猜行列。网站交互视图应如实标明与导出原图的区别。
- 继续保留原图、完整表和 CSV/SVG 下载；不拉伸原图，不重算数据，不把空白缺失值写成 0。

关闭标准：窗口边界、原图比例、行列与 CSV 一致；鼠标/触摸/键盘都可读值；完整标签与选择状态可读；不引入重新绘图请求。手机原图查看继续保留 UX-19 的功能。

### W02 · 固定可见的原句—编码—主题关系（待实施）

把关系图从只依附于切换画布的状态中独立出来，作为 **Coding 之后、Analysis 段自身常驻的主图**，仍属于左演示右文字区。设置直接锚点，五模块的 Analysis 入口可直接定位到它。滚动经过该段就必须看到实际节点和连线，不能只看到一个导航标题。

- 默认展示一个已有 Bologna 原句、一条编码路径和实际分支。宽屏按“高亮原句 ↔ Code / 子编码 ↔ Theme / 分组”排布，原句直接进入主图，不只显示代表文档的圆点。
- 悬停、键盘焦点或触摸选择任一部分，连线与关联节点一起强调；完整原句、路径和源 ID 可查看。只展示实际保存的关联，示例子集不冒充完整项目网络。
- 手机改为带连线的纵向关系图，保留分支与明确角色名称；不再以隐藏所有连线的文字按钮列表代表完整图。
- Coding 展示“怎样选句并赋码”；Analysis 展示“已有编码之间及其原句的关系”，两幅图的任务、构图和交互保持区别。

关闭标准：不点击标题也能在正常滚动中找到关系图；桌面和手机都实际显示节点与连线；可从任一部分核对完整原句与真实路径；连线端点均为真实节点。

### W03 · 演示区视觉收束（待实施）

每段只保留一个主图、一句用途和一个主要入口。统一图中字体、标注、线宽、间距、选择色与比例；长标签使用可读的换行或独立详情，不同时堆叠工具栏、下拉框、说明和装饰。优先依靠选中关系、流程状态和实际数据变化表达逻辑，减少循环装饰。原始操作录屏、完整方法、数据和来源仍按需到达。

关闭标准：Import/Coding/Analysis/Plotting/Export 各自能被识别；图例、轴标签、节点和正文在普通桌面及 390px 下无需额外浏览器缩放即可阅读；用户视觉确认单列，不由测试通过替代。

### T01 · 首次进入、空项目与继续工作（待实施）

建议采用三种状态：

1. **首次使用**：显示空项目起步页，主操作“导入文档”，次操作“试用 Bologna 示例”；可创建项目或恢复现有项目。空白不等于空屏，只提供下一步所需的信息。
2. **已有项目**：继续明确选定的项目与最后阅读位置，不清空原有工作。当前初始化打开列表首项的行为需要另行调整。
3. **示例模式**：明确标注 Bologna、示例或只读状态，以及进入自己的本地项目的路径。公开演示与可编辑临时副本不能混称。

实施涉及启动默认行为，需独立范围与回归；本轮没有删除示例、重置项目或改动默认模块。正式下载入口仍遵守现有发布门禁。

关闭标准：全新与已有工作区分别测试；用户能分辨示例与自己的项目；刷新、取消引导、返回与恢复均不丢数据。仅使用 Bologna 临时副本验证。

### T02 · Coding 层级与高亮（待实施）

右侧由平铺标签变为清楚的父子树，显示分组/主题、子编码与当前编码的完整路径。不能只靠色点表达角色，也不能把无父级编码一律宣称为研究者已确认的主题；沿用项目已有父级关系，不替研究者重新归组。

正文未选中时采用低饱和的轻高亮；选中时以一个强调色联动原句、编码和完整父路径。重叠标注通过数量提示及可展开列表表达，保留每个实际标注的可达性，不把多种颜色混铺在长段正文上。不改项目保存的名称、颜色、父级关系和标注范围。

关闭标准：从一段原句能辨认其所有实际标注与父路径；选中任一码可准确回到范围；同名编码依靠稳定 ID 与完整路径区分；现有筛选、编辑、合并和重叠标注行为保持。

### T03 · 阅读定位和已读状态（待实施，分两步）

紧凑固定栏建议内容：文档切换/名称 · 当前段落 · 返回上次位置 · 当前 Theme/Group › Code。旁边的文档缩略条区分当前位置与已有编码范围。手机文档切换同时覆盖尚未关闭的 UX17-03，避免新增另一套入口。

- 先做位置记忆与从现有标注派生的编码范围分布，按稳定项目/文档 ID 区分；恢复时以真实段落或字符锚点定位，避免仅保存易漂移的像素距离。
- “已读”必须由用户明确标记，并能撤销；滚过不等于读完，有编码不等于完成分析。不能把阅读或编码覆盖直接显示为研究完成度。
- 已读标记属于新增工作流元数据，实施前明确是否仅当前设备保存、是否随项目导出及跨设备恢复；不把结构化进度偷偷写进研究备忘录。本轮仅建议，未新增存储字段或 schema 变更。

关闭标准：长文滚动中不丢文档和所选编码上下文；恢复与文档切换准确；固定栏不遮挡原句或键盘焦点；位置、已读、已有编码三种含义清楚且不混用。

### T04 · 工作台与网站同一视觉体系（待实施）

统一 QT 可见标志、颜色、边框、按钮、编号与字体层级；工作台仍保留适合长文阅读的清楚正文与紧凑操作。网格可以留在导航与框架，访谈正文使用干净、高对比背景；不把每个操作控件都变成夸张的手绘形状。不调整统计图的坐标或已有导出结果来追求手绘效果。

### T05 · 可跳过的首次引导（待实施）

网站首页保持简洁，不增加强制遮罩教程。工作台首次使用提供三步轻提示：导入文档 → 选句并赋码 → 查看关系或导出。允许 Skip、关闭、稍后从 Help 重开；完成一项就停止解释该项，不强制开启所有能力块。已有项目用户可直接继续工作。

关闭标准：跳过不影响导入和编码；键盘、触摸、Escape、焦点返回可用；遵守减少动态效果；示例和真实空项目的提示各自准确。
