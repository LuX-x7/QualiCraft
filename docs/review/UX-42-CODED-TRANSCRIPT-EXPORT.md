## 用户要得到的文档

第五模块增加 **Coded transcript / 编码原文对照文档**，与Analysis Table、Narrative Analysis、五图和复现代码一起交付，也能单独下载，用于作者逐句整理叙述。用户要求的是Coding工作台中“完整正文＋准确高亮＋右侧归属树”的内容关系和阅读布局，而非仅有CSV或一张工作台截图。

桌面／纸面结构：

```text
文档名、项目版本、导出时间、编码范围说明

完整正文与原段落编号                     对应原句的归属树
01 …未编码的语境仍保留…                 Theme / 已保存根组
   [范围A：高亮原句]                    └─ Category / 已保存中间组
   …                                    ├─ Code A · 范围A · 标注ID
02 [范围B：同一句上的两个编码]            └─ Code B · 范围B · 标注ID
                                       另一条归属分支（如存在）

树中的标注条目 ↔ 原句范围；正文文字可以选择、复制
```

上图仅是结构示意，不含研究资料或新分析结果。原样指忠实呈现Coding已保存的文本、高亮及归属；导入前PDF／Word的原始版式并未由现有导入器保存，不承诺还原它。应用的导航、编辑按钮及AI候选面板不构成研究文档正文。

## 必须保留的信息和对应规则

1. **完整原文**：保留选中文档的全文、段落顺序、换行和Unicode文字，包括未编码语境；不能只导出视口内内容或只拼接引文。默认导出完整文档，临时搜索／编码筛选不静默删掉正文。单份、所选多份和全部文档的范围在导出前明确显示；多份各自有文档名和起始位置。
2. **真实高亮范围**：以原文的Unicode `[start,end)` 坐标还原。高亮边界、段落编号和标签关系与Coding一致，不改原句、不把凝练或转述替代原文。同范围多码、部分重叠、嵌套和跨段标注全部保留；标签多于颜色时仍可逐条识别。
3. **每处原句旁的归属树**：使用实际 `code_id` 与保存的 `parent_id` 链，从根组到所有中间层，再到实际被标注的节点。常见三层以Theme → Category → Code展示；已有任意层深、父级直接标注、未归组编码也要忠实保留。同名不同路径分别显示；路径仍同名时用稳定ID区分。
4. **层级不是自动研究解释**：当前码本只有父子结构，未统一保存独立的Category语义类型。未来报告设置应明确层级角色；没有Category／Theme时按已保存的Code／Group显示，不制造层级或把所有父节点自动认定为研究主题。TA／CA／Comparative共用编码证据导出；Comparative的集合与配置结果另有方法输出，不从树推断。
5. **一一可核查**：每条关联保留文档ID、标注ID、编码ID、原句范围和完整名称路径。HTML的高亮与树条目可双向定位；同一标注跨段可在相关段重复提示，但仍标为同一标注ID，不能增加保存关联数。Word／PDF用同一短标识及原句范围保持对应，不能以空间靠近作为唯一联系。
6. **当前确认记录**：默认展示已保存／确认的编码，未采纳建议不混入；来源按记录保留。manual／HUMAN说明录入路径，不能据此推断独立人工作者；已知助手分析需随实际披露说明。备忘录可明确选择纳入，默认不把全部笔记或浏览器状态一并公开。
7. **阅读状态分开**：Keep／Resume是浏览器位置，不是研究编码；Read／Revisit是手动项目标记，不证明理解程度。本输出默认突出原文与编码，现有JSON v5阅读标记导出规则保持不变。
8. **可复核版本**：注明导出范围、生成时间、项目／文档／标注来源及冻结版本标识，区分正文范围数与编码关联数。源文或码本改变后，产品内保存的旧成果提示检查／更新；旧文件不被静默覆盖。导出不改项目正文、标注、审计或统计。

## 输出格式建议与优先顺序

用户已明确的是输出内容、左右布局和写作用途。下列格式组合是实现建议，未冒称用户已逐项确认；具体格式范围在实现切片中冻结。本轮没有新增这些能力。

| 格式 | 用途 | 必须做到 |
| --- | --- | --- |
| 自包含HTML | 最接近Coding的本地阅读与逐句证据核查 | 打开即可见完整正文、高亮和右树；可悬浮／触摸／键盘选择并双向定位；样式与必要资源本地内置，禁用脚本后仍完整可读；手机逐段排列正文与归属，保留全部条目 |
| 可编辑DOCX | 作者整理Narrative Analysis、复制原句和添加写作笔记 | 正文与树均为可选择／编辑文字；按段落使用两栏结构，保留树线／缩进及关联标识；不把正文和树栅格化成截图。外部修改不会自动回写研究项目 |
| PDF | 固定分页、交给supervisor检查 | 正文与右树同页对应、长段与长树可续页且标明延续；不截断、不覆盖、不靠缩小成难读字号塞入一页。最终页面尺寸与排版通过实际导出检查 |

建议先做共享的冻结数据／范围／路径映射，以自包含HTML核查内容和双向对应，并优先提供方便写作的可编辑DOCX；PDF在分页布局稳定后单列。最终门槛是完整、可读、可复制并便于写作的高亮原文与右侧树形对应，不能只交付截图、仅CSV或依赖正在运行的工作台。独立输出优先，研究报告可选择将其作为证据附录；保留现有四导出及所有图包。

导出必须保留可读正文，同时对HTML／XML内容做正确转义；本地文件不携带模型密钥、会话token或无关应用状态，不向外部网址加载资源。研究者编辑报告不会静默改写原文／计数。真实资料输出继续私有，不能因增加该功能而自动进入Git、公开网站或分享审核包。
