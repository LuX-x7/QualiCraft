## 边界与待决能力

- AI可以提出编码建议，用户逐条接受／拒绝；不是一键自动确认编码。任何外部模型请求需配置、预览并确认。
- 本地版资料在本机；在线版资料保存在QT服务器的独立账户，不能写“在线上传但不离开本机”。LLM发送是第三个独立动作，需明确披露。
- 用户可配置兼容的LLM API；学院统一网关可作为将来接入路径，但当前没有faculty管理、统一配额、权限隔离或机构共享密钥部署，不冒称已有。不在公开客户端写入共享密钥。
- 目前不支持多人同时编辑同一项目。先保留项目导出／恢复与审核；实时协作涉及冲突、访问控制和审计，单列未来能力，本轮不新增。
- GitHub Pages自动发布已获授权，但仓库所有者设置及发布工作流尚未完成。当前网址仍为QT服务器入口。
- 开机自启因xiaolu无sudo权限而阻塞；不得把进程恢复当OS开机验证。
