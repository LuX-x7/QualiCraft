## 1. 当前使用方式

Coding 顶部 Overview 默认折叠。展开面板在固定栏下方、随正文滚走；默认固定栏保持桌面141px、390px手机134px。手机 Themes & codes 入口移到文档工具行，保留原树和搜索／编码工具。

上轨为手动阅读标记：Read用绿色，Revisit用赭色纹理；下轨为现有编码范围的视觉并集。两轨都按完整原始 Unicode code-point 坐标 `[0, text_length)` 绘制。实线为当前阅读位置，虚线为预览，两者独立。细范围可用最小可见宽度；准确值必须从列表读取。没有阅读／编码完成百分比。

点击轨道仅预览段落。Exact paragraphs 展示状态、完整 `[start,end)`、触及本段的实际标注数与不同来源范围数，每页12项，可按任意段落编号定位预览；Exact source ranges 可选择本段／全文，每页10项，也可按当前列表中的范围编号选取。选中来源后显示完整原句、所有真实标注ID、编码ID和完整主题路径。不存在按名称合并同名编码。

Go to source 才跳转并聚焦原文，选中范围横跨多段时保留完整身份与各段高亮。列表、编号输入、按钮、原生select、Enter／Space／Escape均可操作，不要求拖拽或悬浮；Escape关闭概览并返回按钮焦点。面板覆盖正文时标记动作暂停，避免误标看不到的段落。

## 2. 范围与身份规则

- 使用当前文档的有效 annotation ID、code ID和完整原始范围；同一编码／范围记录不复制。全篇计数按标注ID，不因跨段而重复。
- 同一 `(document_id,start,end)` 下多个编码是多条标注、一个原句范围；展开保留每条ID和路径。部分重叠的两个范围仍是两个来源，不能按合并后的笔迹数反推数量。
- 每段只显示与该段相交的实际记录数；**各段 touching 数不能相加**。整篇53条标注／52个来源范围与原工作台定义一致。
- 相邻／交叠范围可连成一条笔迹，只表示视觉并集，不生成新的共现定义或分析输出。源端点是完整原句范围，列表不会用逐段裁切端点替代它。
- 重命名／删码后从当前项目重算列表；最后一条来源标注删除后清除旧预览；阅读状态独立保留。失效阅读metadata不套到新原文，但编码轨道仍可查看。
- 段落／来源列表分页；段落触及计数使用排序边界查找，避免构造“每段×所有标注”的巨大展开表。SVG笔迹没有数万个Tab目标。所有来源仍可从精确列表到达。

## 3. 位置、筛选与网络语义

双轨和全篇列表始终明确 Entire document，不因外层搜索／主题筛选悄悄缩短比例。跳转所需的任一段落被过滤时，必须明确选择 **Show full document & jump** 才清除筛选；预览、切页、选择来源本身不清除过滤。原句跨段且仅部分可见也遵循同一规则。

展开／预览／跳转不覆盖原来的浏览器 Resume，也不写 Read、项目、审计或快照。临时导航保留当前浏览位置，刷新工作区不会强制回到最初的预览段。Resume 返回原锚点；**Keep this reading position** 才明确替换本浏览器位置。浏览器存储被禁用时可以继续查看与跳转，保留位置会明确提示无法记忆，不伪报成功。

文档／项目按稳定ID隔离，切换文档默认关闭概览；阅读标记仍使用32A的即时入库、撤销、v5 JSON、研究编辑快照规则。关系图的原句定位优先于旧概览预览，打开概览不覆盖网络来源，返回关系图保持原选择。
