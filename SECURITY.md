# Security notes

Please do not report private transcripts, API keys, or identifiable patient information in a public issue. Remove sensitive content and use a minimal reproducible example.

The current application is local-first and binds to loopback. It has not been reviewed for public hosting, clinical use, or institutional data processing. A report about a local data leak, credential exposure, authentication bypass, or unintended network transmission should be sent privately to the repository maintainers before public disclosure.
